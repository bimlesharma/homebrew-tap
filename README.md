# bimlesharma/homebrew-tap

Homebrew tap for **CleanPulse** promo / alpha macOS builds.

```bash
brew install --cask bimlesharma/tap/cleanpulse
```

Binaries are published to [bimlesharma/cleanpulse-releases](https://github.com/bimlesharma/cleanpulse-releases). Application source remains private.

Alpha builds are ad-hoc signed and not Apple-notarized.
